# english-concept-video

用 AI 制作英语学习短视频的流程手册。先确认排版、字幕、配音、音效、画面，再成片；交片时同时配上视频文案。

完整规则在 [SKILL.md](./SKILL.md)（技能名：**英语成片**）。本仓库只放流程文档，不存放成片、口播音频或画面素材。

## 这个仓库做什么

这不是一个自动剪辑工具，而是一套可以反复执行的出片规则：选题和脚本确认后，再出排版静帧、配音小样和音效小样，五项都点头后才渲染成片。

适用于概念讲解、跟读、文章口播、情感播客、情景口语等英语学习短视频，不限于某一种片型。

## 怎么用

直接说要使用的出片风格，例如「用情景动画做一期点咖啡」。没有点名时，按片型自动选择：

| 片型 | 默认风格 |
| --- | --- |
| 概念讲解 | 简笔讲解 |
| 跟读、文章口播 | 风景跟读 |
| 情感 / 关系对话、双人播客 | 夜灯播客 |
| 生活情景口语（点咖啡、打车、上班等） | 情景动画 |

新拆解一种视频类型后，会给它起一个短名，并写进 `SKILL.md` 的「出片风格」一节。现有风格按使用反馈慢慢改，不会擅自大改。

## 出片风格

目前有四种。细节和禁止项以 [SKILL.md](./SKILL.md) 为准。

### 简笔讲解

奶油色底加原创黑线简笔小人，没有顶部栏目名。英文在上（亮黄）、中文在下，两条独立的圆角字幕条。重点词用画面中央的大词卡，结尾跟读。适合沉没成本、幸存者偏见这类概念讲解。

### 风景跟读

暖色风景空镜（海、草原、日落等），少切镜。顶部是栏目名加黄条主题（不放 Zion），标题用本期主题。中文在上、英文在下且更大。适合跟读和文章口播。

### 夜灯播客

暖灯夜景加两人剪影，双人对话。Zion 是第一人称男声，女声搭档默认叫 Mia。英文按说话人分色（Zion 亮黄、Mia 淡粉），中文在下。适合情感、关系话题；坐着聊感受用这一套，把对话演成生活场面则用情景动画。

### 情景动画

风格化卡通人物走进一个生活场景，先对照别扭或课本式说法，再给出更自然的说法，最后跟读。角色和剧本必须原创，不要写实人脸。一条大约练 4–8 句，默认 45–90 秒。

## 硬规则（所有片子都适用）

1. **先确认，后成片。** 排版、字幕、配音、音效、画面都要点头后才能渲染。
2. **交片必须带文案。** 成品和短视频文案同一轮交付。
3. **不要擅自发布，也不要在成片里加背景音乐。** 背景音乐由制作者自己加。
4. **不要搬运、不要虚构数据。** 可借鉴排版配方，不要复制他人的画作、角色或口播稿。
5. **成片大于约 15 MB 就拆段交付**，并保留拼接清单。

通用规格：竖屏 9:16，720×1280；标题区不放 Zion；最下一条字幕下沿约在画面高度的 85%–87%，不要贴底。
